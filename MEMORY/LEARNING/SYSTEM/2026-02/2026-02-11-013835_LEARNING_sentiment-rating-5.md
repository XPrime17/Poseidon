## Assistant Response Context

That error means you put the URI in the wrong field. Google Cloud has **two separate fields**:

- **Authorized JavaScript origins** — just the base URL, **no path**:
  ```
  http://localhost:5678
  ```

- **Authorized redirect URIs** — the full callback path goes here:
  ```
  http://localhost:5678/rest/oauth2-credential/callback
  ```

Make sure the callback URL with `/rest/oauth2-credential/callback` goes in the **bottom field** (redirect URIs), not the top one (JavaScript origins).
