## Workflow

### Step 1: Collect Centre Info

Use AskUserQuestion to gather:

**Required:**
- Centre name (e.g., "East Gwillimbury", "Canton")
- City and province/state (e.g., "Canton, MI")
- Centre Director name and title

**Optional (defaults available):**
- Expected monthly call volume (default: 300)
- Average enrollment value (default: $2,400/year)
- Dedicated phone number (if already provisioned)
- Governing jurisdiction (defaults from city: ON → Ontario, MI → Michigan, TX → Texas)

**Pricing (if finalized):**
- Setup fee
- Monthly retainer
- Multi-location discount percentage

### Step 2: Generate SOW

→ Run `SOWGenerator.ts` CLI with collected params:
```bash
bun run SOWGenerator.ts --centre "[name]" --city "[city, state]" --calls [X] --contact "[name, title]" --setup [X] --monthly [X]
```
→ Capture SOW reference number (SZA-SOW-YYYY-NNN)

### Step 3: Generate Service Provider Agreement

→ Follow `GenerateContract.md` workflow
→ Customize ContractTemplate.md with:
  - Client: Code Ninjas [Centre Name]
  - Pricing: match SOW Section 7 exactly
  - Jurisdiction: derived from centre location
  - Compliance: PIPEDA (Canadian) or standard (US)
  - Reference SOW as Exhibit A using captured reference number
→ Assign agreement reference: SZA-SPA-YYYY-NNN (matching SOW number)

### Step 4: Cross-Reference Check

Verify consistency across both documents:
- [ ] "Code Ninjas [Centre Name]" matches exactly in both
- [ ] Pricing in SOW Section 7 matches Contract Section 3
- [ ] Scope in SOW Section 3 aligns with Contract Section 1 services
- [ ] Timeline in SOW is 3-5 business days (not generic 3-4 weeks)
- [ ] Data handling in Contract covers call recordings and transcripts
- [ ] Compliance matches jurisdiction (PIPEDA for Canada, state law for US)
- [ ] Contract references SOW as Exhibit A with correct reference number

### Step 5: Package Summary

Output a summary cover page:

```
═══════════════════════════════════════════════════════════════
  DEAL PACKAGE — Code Ninjas [Centre Name]

  Prepared by: Sub-Zero Automations
  Date: [Date]
  Solution: Speed-to-Lead Voice AI Agent ("Cimo")

  Documents Included:
  1. Statement of Work (SZA-SOW-[YYYY]-[NNN])
  2. Service Provider Agreement (SZA-SPA-[YYYY]-[NNN])

  Investment Summary:
  Setup Fee:        $[amount] (one-time)
  Monthly Retainer: $[amount]/month
  Deployment:       3-5 business days
═══════════════════════════════════════════════════════════════
```

### Step 6: Deliver

Output both documents in sequence with clear separators. Remind user:
- Recommend legal review before client delivery
- Documents are in markdown — ready for Google Docs / Notion / PDF export
- SOW is valid for 30 days
- Both SOW and Agreement should be executed together

**Optional: Email delivery**
If requested, send the package via Resend API to the Centre Director or Scott.
