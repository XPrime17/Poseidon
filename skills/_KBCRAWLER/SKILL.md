# _KBCRAWLER -- Nightly KB Crawler

Automatically crawls Code Ninjas centre data from `services.codeninjas.com` API and writes structured `<doc>` tags to each centre's Google Doc KB. Voice agents pick up fresh content on next call via `{{knowledge_base}}` injection.

## Architecture

```
services.codeninjas.com API (JSON, no auth)
    ↓ fetch + parse additionalSettings
Transform to <doc> tags (tiered priority, 10K char cap)
    ↓ POST to n8n cloud webhook
Google Doc (auto-generated section overwritten, manual section preserved)
    ↓ (at next call)
n8n reads Google Doc → retell_llm_dynamic_variables.knowledge_base
```

## Data Extracted

| Tier | Category | Source |
|------|----------|--------|
| 1 | Store hours, contact info, programs | Top-level API fields |
| 2 | Camp pricing, schedule, extended care | `additionalSettings.programs.camps` |
| 3 | Upcoming events (next 30 days) | `additionalSettings.customPage.events` |
| 4 | Program descriptions | `additionalSettings.programs.additionalPrograms` |
| 5 | Social media links | `additionalSettings.customPage.socialMedia` |

## How to Use

### Manual crawl (single centre)
```bash
cd /root/kb-crawler
bun run crawl.ts --centre east-gwillimbury-on-ca --dry-run   # preview
bun run crawl.ts --centre east-gwillimbury-on-ca              # write
```

### Manual crawl (all centres)
```bash
cd /root/kb-crawler
bun run crawl.ts --dry-run    # preview all
bun run crawl.ts              # write all
```

### CLI flags
- `-c, --centre <id>` — crawl single centre
- `--dry-run` — preview output without writing
- `-v, --verbose` — detailed output
- `-h, --help` — show help

## Scheduling

- **systemd timer:** `kb-crawler.timer` runs at 2 AM ET (06:00 UTC during EDT)
- **Check status:** `systemctl status kb-crawler.timer`
- **Check last run:** `journalctl -u kb-crawler.service --since today`
- **Manual trigger:** `systemctl start kb-crawler.service`
